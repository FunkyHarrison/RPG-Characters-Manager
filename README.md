# RPG Character Manager

A command-line Python application for managing RPG characters.

## Features

- Create characters
- View saved characters
- Damage and heal characters
- Prevent health from dropping below zero
- Prevent health from exceeding maximum health
- Delete characters
- Save character data using JSON

## How to Run

Run the following command from the project folder:

```powershell
python RPG_Characters_Manager.py
```
